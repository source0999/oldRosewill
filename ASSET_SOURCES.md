# Asset provenance

The files in `assets/` were downloaded from public `https://rosewill.org/images/...` endpoints while recovering the site on 2026-11-17. Original page HTML is retained verbatim under `source-snapshots/`; its image URLs provide the exact path for every asset. Filenames preserve the downloaded source filename preceded by an inventory number from the original recovery.

No third-party replacement photography has been introduced.
